# Viral Instagram Reels Template Creator

A Vite + React + TypeScript starter project to build a web app for creating viral Instagram Reels templates. Includes Tailwind CSS, Zustand, ffmpeg.wasm, Howler.js, react-beautiful-dnd, and msw for a mock API.

Quickstart

1. Install dependencies

   npm install

2. Start dev server

   npm run dev

3. Build

   npm run build

Notes

- This is a scaffold. Replace placeholder assets with your own videos and audio.
- Export uses ffmpeg.wasm in the browser which may be slow for large videos. Consider a server-side render for production.
